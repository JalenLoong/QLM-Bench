# Lift Basket semantics and local demonstration scope

Use the reviewed OASIS basket with source-authored mass/material/collision unchanged, Go2 single FL, original RAMBO controller/checkpoint, native9 and desired force zero. The source root scale0.3 is included in geometric calculations. Convex-hull support vertices are used only to compute exact transformed mesh extrema; they do not replace the physical collision geometry.

The user lowered success from6cm to2cm: minimum worldZ over the entire basket geometry minus floorZ is at least0.02m, robot not fallen, for3 consecutive50Hz policy ticks. Initial2.1s settling is excluded so spawn clearance cannot count. Basket tilt and target-pair contact do not gate success. Contact remains explicitly unknown/invalid diagnostic evidence. Old6cm attempts keep their original profiles and results.

The accepted demonstration sequence threads the entire FL collision envelope beyond the handle far side before controlled lifting. This is separate from physical task success and does not assert observed pair contact. User accepted pilot-a6, then clarified ego visibility is advisory, not a hard condition. Remove ego visibility from phase transitions, lift-progress pausing and demonstration acceptance; retain its diagnostic measurements. First two local demonstrations used the earlier accepted implementation, later ones use the exact documented visibility-only update; per-episode source hashes distinguish them.

Task columns remain under the existing data schema. task.progress is actual minimum basket clearance in metres. task.goal.position contains initial basket XY reference and clearance threshold in Z; XY is not a success region. RawN/N+1, CanonicalN plus separate terminal,50Hz policyRGB/action,25Hz observer-only and authoritative simulation timestamps remain unchanged. Terminal RGB/state are copied before reset; no dummy terminal action, attachment joint, teleport or external object wrench.

The latest authorized scope is ten successful local demonstrations, initialX±1cm andY±0.5cm only, fixed asset/orientation/height and other a6 parameters. Predeclared seed900942 scenarios, runtime seed42, whole-episode8/1/1 split and max3 attempts per slot. This replaces the earlier50 target for the current work. Pilot/failures/interruption are excluded from the successful collection. No Hugging Face upload, model cache, training, source commit/push or v3 modification is authorized by this batch request.

Runtime is isolated in workspace repos/RAMBO_Data-v2-lift-basket to preserve concurrent DATA008 changes. WAM v3 is not used or edited. Evidence and actual completion status are in the DATA009 plan and workspace runs/audit/v2/DATA-009/20260926T060352Z/local-ten-20260926T130524Z; this decision is not itself a claim that all ten episodes have completed.
