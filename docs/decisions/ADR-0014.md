# Original-weight block offload and declared local trial evaluation

Accept the explicit16-block CPU-master/CUDA-forward deployment and declared ten-trial
nominal-scene evaluation, with measured actual-RGB and complete-outcome gates. This
preserves model/physical/data identities and trades wall time for GPU resource headroom.
The earlier numerical-only visual acceptance is withdrawn; invalid attempts remain.
Formal public benchmark scores stay null until accepted case/protocol gates pass.
