# External physical button over the unchanged native9 dataset contract

User approved Industrial Button asset review-v3, cap front(.56,.10,.30)m,20mm slide,12mm threshold/3 policy ticks and not-fallen success. No release is required. The cap and housing use the externally sourced appearance; physical collision/joint/spring parameters are authored additions, separately recorded. The original quadruped controller/checkpoint and policy camera geometry remain unchanged; approved observer is front-side and diagnostic-only.

The object tracked by existing task.object columns is the moving button cap's runtime rigid-body frame. task.goal.position is the reviewed rest-front point plus press axis times success displacement. task.progress is measured axial cap displacement in metres, not box translation or an arbitrary success score. Named task-review metadata carries cap pose/front, axis, travel, threshold and consecutive count. Both contact-pair columns retain explicitly invalid false placeholders backed by diagnostic/unknown metadata; contact is not a success gate.

Success is evaluated at unique consecutive50Hz policy boundaries before reset. Non-policy physics samples and duplicate checks cannot add hold ticks. A fall invalidates success. Recorder completes the last command, owns a copy of terminal state/RGB, disables further capture, and only then permits reset; an invalid partial interval cannot become valid pilot data. No after-start cap pose writes, animated success, external object wrench or success-driven visual markers are part of the expert.

Raw/canonical schema/profile/action/camera identities remain unchanged. A pure dataset-side task mapping is shared by recorder and offline packaging so the latter does not require Isaac. Push Box mappings remain numerically identical and regression tested. WAM v3 is neither edited nor imported; isolated WAM v2 changes are governance only. This approval does not authorize collection batches, upload, model preprocessing/training, commit or push.

Physical/data acceptance results are recorded in the DATA-008 plan and workspace evidence; this ADR records semantics, not an unrun success claim.
