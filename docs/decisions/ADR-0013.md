# Physical-only synchronous online transport

The user-requested online implementation reuses the fixed2.0.0 compatibility messages,
profiles and command history. A separately versioned live envelope carries actual raw
RGB and explicit measured root state without modifying any frozen specification bytes.
QLM owns command execution and physical clock; WAM owns model sessions and preprocessing.

The first execution profile is single-env, synchronous, sixteen20ms native9 commands,
with zero physics/controller steps during model/network waits. Terminal evidence is copied
before low-level reset and incomplete tails end the model episode. Retries preserve message
and chunk identities; uncertain execution never repeats. Length-bounded JSON/base64 over
localhost keeps the CPU transport independent of framework serialization and simulator code.

This adds online engineering capability without changing task predicates, physics,
controller, training data, checkpoint/normalizer semantics or formal evaluation protocol.
A successful physical/mock transport test is not evidence that a learned WAM policy succeeds.
