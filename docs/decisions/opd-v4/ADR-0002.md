# Native1/2、400-update mixed-task OPD 的当前目标

日期：2026-10-24。接受依据为用户本轮 NFE/documentation 指令；这是设计决定，
不声称新配置已实现或已经通过模型/硬件验证。

## 动机
用户报告，25/50→旧2/4时闭环能力和未来video prediction质量没有明显下降，
25/50→1/2时两者明显下降。因此正式student改为State1/Action2，检验Streaming OPD
能否恢复低预算损失。只记录定性动机，不编造具体成功率差值、video metric或恢复结论。

## 决定
1. Student/actor/learner/deployment统一native FM velocity、Euler full-denoise1/2，
   网格由既定scheduler生成。Teacher25/50仅为高质量基线推理，不扩大DMD单次score query。
2. 固定400成功student updates、2000fake updates、9600真实contexts；8streams×3slots，
   5F→1S。失败attempt成本另计，达到预算后不等待活跃episodes自然结束。
3. Global episode-level round-robin优先confirmed starts较少task，平局可恢复；
   同task train shuffle deck与运行/预留最多2个。只在真实terminal/reset切换。
4. Student/fake context外层loss等权，本地1/3、DDP mean8，无task-frequency或1/L系数。
   长episode更多累计监督是主动选择的目标，不等同于更难或更大梯度，不要求每task10%。
5. 固定training horizons：Push19.2、Press/Lift/Kick24、Oven/Valve32、
   Sweep/Fridge/Drawer/RoomDoor40秒；保持标准evaluation horizon和success criteria独立。
6. 所有8条streams的Native MuJoCo physics、RAMBO与OSMesa/llvmpipe均CPU only；
   8×MI355X用于模型。无MJWarp/GPU EGL，无dynamic stall detection。
7. 冻结评估比较teacher25/50、initialized student1/2、OPD student1/2；旧2/4仅历史参考。
   保存计划继续每10次及安全/最终边界，并建议保护S200/S400比较点。

## 保留的合同与历史
仅supersede ADR-0001的student NFE相关默认决定，补充预算与mixed-task目标；
它的两阶段、三角色、LoRA、DMD公式、完整当前链梯度、detach/history/KV、
5F→1S与CPU-only边界继续成立。ADR-0001原文、已归档工程与实验记录不修改。
旧task_balance_v1为未实施提案，不纳入当前目标，也不改写其历史文本。
共同step5000 SFT、normalizer、frozen资源、train800场景/状态/seed身份保持。

## 实现与证据边界
旧2/4主体已完成本地实现；源码仍有固定2/4、200预算、旧horizons和rank-strided reset。
详见[只读差异报告](../../current/opd-v4-documentation-sync.md)。本轮只改文档，
后续代码变更等待用户确认。旧receipt不能证明1/2 parity、backward或400-update readiness。
新配置应使用新的训练/采样/调度身份，不静默恢复旧2/4 OPD checkpoint。
AMD/full5B/八流/400updates/OPD性能均not_run。继承SFT不自动开启额外Stage1训练。
