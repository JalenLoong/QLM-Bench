# 训练兼容性、来源记录与执行快照

用户明确要求删除startup acceptance硬门槛、保留单/八卡工程准入、兼容管理员现有run/smoke，并补EMLINK回退。
ADR-0004中人工startup acceptance和全执行配置必须永远相同的约束由本决定替代；算法与资源完整性要求保持。

全源码与run名称用于追溯；实际训练文件语义指纹和必要模型/数据/算法字段用于工程与恢复兼容性。
已审阅的OPD-013到OPD-014过渡登记明确旧版来源指纹，不接受未知版本的无条件升级。
旧run/report/checkpoint均不重写；新续接使用独立执行snapshot及原run关联，并保留active/unknown job防重。
已提交执行不接受env setup原地变更；退出后可记录新的运维配置。Publish消费完成产物，与训练环境解耦。

完整payload hash、checkpoint内部identity、state/rank/RNG、normalizer、sampler、pool来源/split及真实工程结果仍严格检查。
JSON语义等价和注释变化不影响运行兼容性；profile固定合同、runtime文件清单和版本迁移需有负例/恢复测试支持。
EMLINK仅改变物理存储方式，不改变manifest或任何训练数据；存储错误不能一概吞掉。

接受依据：原版schema fixtures、未知/损坏/真实变化负例、tiny CPU连续与恢复参数精确比较、
两种Python语义指纹对照、真实既有资源只读验证及本地全CPU回归。目标AMD执行仍需独立验收。
