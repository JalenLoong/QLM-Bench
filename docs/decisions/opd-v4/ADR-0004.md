# Stage2-only OPD Slurm chain

用户确认本次不启用teacher-generated trajectories SFT，并要求独立OPD提交链。
采用prepare(CPU既有资源校验)→single-smoke→eight-smoke→formal；不调用旧SFT pipeline。
已有checkpoint/normalizer/frozen resources/prompt embeddings和prepared reset pool是输入；
Stage1固定0updates，无离线视频/cache/normalizer/原模型转换或自动HF上传。
训练算法与CPU-only四足合同不变，原可选Stage1代码留作独立实验，不进入此链。

默认只preview。真实提交使用同机1task的held afterok链、逆序release、失败撤销及未知job对账；
显式through支持smoke后提供既有startup acceptance，成功前缀不可重跑。实际Slurm/AMD尚未验收。
Formal不继承smoke权重；只有显式resume才恢复完整OPD checkpoint，物理连续性仍中断。
完整round安全停止信号发给learner ranks，不提前终止torchrun agent或CPU feedback workers。

README改为OPD入口，旧SFT指南迁至WAM docs/legacy/mujoco-sft-submission.md。
ADR-0003的算法/预算/保存选择继续有效；本决定只增加独立调度与管理员路由。
