# Refresh reset-derived root-link velocity without stepping

Retain original COM reset setter semantics and invalidate derived root-link velocity
and combined-state buffers at the QLM shared reset boundary. The pinned backend
COM setter leaves the root-link velocity timestamp current. Do not replace state
with literal zeros, change reference frames, modify pinned upstream or add a physics
warm-up. A missing pinned cache layout fails closed. Actual three-task acceptance
and historical limits are in [current reset evidence](../current/reset-state-freshness.md).
Future data use receives fresh measured state; historical releases/caches stay immutable.
