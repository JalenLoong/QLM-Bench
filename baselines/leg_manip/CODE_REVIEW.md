## 修复清单

| 模块 | 已验证的问题 | 修复与回归 |
|---|---|---|
| 按钮物理 | 按钮与内部面板自碰撞，5N按压仍被顶到负位移 | 显式排除内部body对，保留对机器人碰撞；原生物理验证5N按下和弹簧回位 |
| SLERP | 近反向向量走错弧，端点被扰动 | 使用实际垂直分量和atan2，只对真正反向退化选垂直轴；保持端点 |
| 控制器坐标 | 目标/估计器用了机身相对高度，与约定不一致 | 统一为env原点以上绝对高度；控制器观测版本2，拒绝旧权重 |
| 外力随机化 | 同时扰动两条前腿，力在小腿COM而非足端 | 按flag选择操作腿，补足端到COM的力矩，每控制步更新并在重置时清空 |
| 终端采样 | 成功判断漏掉最后一个物理步 | Recorder在自动reset前保留物体关节，记录每步动作后的状态 |
| 摔倒统计 | 同时timeout与fall时掩盖跌倒 | 使用独立的 `env.reset_terminated` |
| 高层闭环 | 新参数晚一帧进入控制器 | 在当前观测构建前更新参数，不重复追加或清空历史 |
| 评估场景 | checkpoint评估顺序改变同seed初始场景 | 每批reset前重新设置独立确定的初始化seed，记录到结果；比较时固定批宽 |
| Planner归一化 | 验证episode泄漏到拟合统计 | 仅用训练episode的帧拟合归一化 |
| Planner续训 | 仅存EMA，不能恢复优化过程且可能混入旧输出 | 原子保存完整训练状态，显式resume，校验数据指纹与配置；拒绝隐式覆盖run |
| 数据契约 | 30维/NaN目标能进入训练 | 验证31维、有限值、flag、单位方向、17维状态和episode边界 |
| 模型配置 | encoder维度设置不能同步到PointNet | 由 `encoder_output_dim` 推导输出宽度 |
| 时间窗口 | 无效窗口训练后才在推理时返回空动作 | 提前检查正整数、窗口关系和UNet时间下采样约束 |
| HF缓存路径 | 不同任务同名文件相互覆盖 | 保留repo内相对路径 |
| HF数据并发 | 其他seed读到部分解压目录 | 进程锁、临时目录、完成标记与原子发布，重试修复旧残缺缓存 |
| HF改名上传 | zip名称与内部根目录不同，返回路径不存在 | 验证唯一Zarr根目录，发布到请求目标名 |

永久失败标记修复，统计排除替代回合；又补了终点重置污染和浮点阈值边界的回归。
最终本地/5090均126项通过，lint/format通过；旧失败权重在GPU验收中明确不合格。
